##  Project Overview

This project focuses on predicting product sales based on advertising expenditure across different marketing channels. Machine Learning techniques are used to analyze how advertising investments influence sales and to forecast future sales performance.

The project includes data preprocessing, exploratory data analysis (EDA), feature selection, model training, evaluation, and sales prediction.

---

##  Objectives

- Analyze advertising expenditure data
- Perform data cleaning and preprocessing
- Explore relationships between advertising channels and sales
- Build Machine Learning models for sales prediction
- Evaluate model performance
- Generate business insights for marketing optimization

---

##  Dataset Description

The dataset contains advertising spending across multiple channels and corresponding sales figures.

### Features

| Feature | Description |
|----------|-------------|
| TV | Advertising budget spent on TV |
| Radio | Advertising budget spent on Radio |
| Newspaper | Advertising budget spent on Newspaper |
| Sales | Product sales generated (Target Variable) |

##  Key Insights

- TV advertising has the strongest positive impact on sales.
- Radio advertising significantly contributes to sales growth.
- Newspaper advertising has a comparatively weaker effect on sales.
- Increasing investments in high-performing channels can improve business revenue.

---

##  Machine Learning Models Used

### 1. Linear Regression

A baseline regression model used for predicting sales based on advertising expenditure.

### 2. Random Forest Regressor

An ensemble learning model that improves prediction accuracy by combining multiple decision trees.
